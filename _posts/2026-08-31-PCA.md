# Principal Component Analysis (PCA)

Principal Component Analysis (PCA) is a dimensionality reduction technique.

PCA transforms the original features into a smaller number of new variables called Principal Components.

The objective is to retain as much of the variation contained in the original data as possible while reducing the number of dimensions.

The Principal Components are not simply selected original features. They are new combinations of the features.

PCA can be particularly useful when a dataset contains many features and I want to reduce its dimensionality, visualise the data or create a more compact representation before applying a machine learning model.

Full Process of Application of PCA

In this example, we use a small dataset containing both numerical and categorical features.

The purpose is to show how PCA can be applied after the different types of data have been appropriately pre-processed.

# STEP 1: Creation of the Dataset

    from sklearn.compose import ColumnTransformer
    from sklearn.decomposition import PCA
    from sklearn.pipeline import Pipeline
    from sklearn.preprocessing import OneHotEncoder, StandardScaler

    data = {
        "Age": [
            25, 32, 41, 28,
            35, 45, 30, 38
        ],
        "Income": [
            30000, 45000, 60000, 35000,
            50000, 70000, 40000, 55000
        ],
        "City": [
            "Milan",
            "Rome",
            "Naples",
            "Milan",
            "Naples",
            "Rome",
            "Milan",
            "Rome"
        ],
        "Target": [
            0, 1, 1, 0,
            1, 1, 0, 1
        ],
    }
    
    df = pd.DataFrame(data)
    
    df

# Separating Features from Target

Before applying PCA, we separate the predictors from the target.

    X = df.drop(columns=["Target"])
    
    y = df["Target"]

X contains the variables that will be used to create the Principal Components.

y is the target variable and is not used by PCA.

This is important because PCA is an unsupervised dimensionality reduction technique.

It does not use the target to decide which directions contain the most variance.

# Separating Numerical and Categorical Features

The dataset contains two different types of predictors.

    col_num = ["Age", "Income"]
    
    col_cat = ["City"]

The numerical variables can be standardised directly, while the categorical variable must first be converted into numerical values.

# STEP 2: Construction of the Pre-Processor

Numerical Pipeline

For the numerical variables, I apply StandardScaler.

    from sklearn.pipeline import Pipeline
    from sklearn.preprocessing import StandardScaler

    numeric_pipeline = Pipeline(
        steps=[
            ("scaler", StandardScaler())
        ]
    )
    
Standardisation transforms the numerical variables so that they have approximately:

- Mean = 0
- Standard deviation = 1

This is important for PCA because PCA is sensitive to the scale of the input variables.

Without scaling, a variable such as Income, which contains values around tens of thousands, could have a much larger influence than Age.

# Categorical Pipeline

PCA requires numerical input, so we first convert these categories into numerical columns using One-Hot Encoding.

    cat_pipeline = Pipeline(
        steps=[
            (
                "imputer_cat",
                SimpleImputer(
                    strategy="constant",
                    fill_value="Unknown"
                ),
            ),
            (
                "onehot",
                OneHotEncoder(drop="first")
            ),
        ]
    )

The SimpleImputer provides a way to handle missing categorical values.

The OneHotEncoder then converts the categories into numerical columns.

# Combining the Pipelines

We now combine the numerical and categorical preprocessing using ColumnTransformer.

    processor = ColumnTransformer(
        transformers=[
            ("num", numeric_pipeline, col_num),
            ("cat", cat_pipeline, col_cat),
        ]
    )
# STEP 3: Creating the Final Pipeline with PCA

We create a complete pipeline containing the preprocessing steps followed by PCA.

    from sklearn.decomposition import PCA

    pipeline_pca = Pipeline(
        steps=[
            ("preprocessor", processor),
            (
                "pca",
                PCA(n_components=2)
            ),
        ]
    )

The parameter n_components=2 means that we want to reduce the processed dataset to two dimensions.

# STEP 4: Fit and Transform

We can now apply the complete pipeline.

X_pca = pipeline_pca.fit_transform(X)

The result is stored in:

X_pca, which contains two columns:

Component 1
Component 2

# What these components are

The two components are new variables created from the processed features.

The first component, Component 1, captures the largest possible amount of variance.

The second component, Component 2, captures the largest remaining amount of variance while being orthogonal to the first component.

Therefore, PCA attempts to represent the original data using fewer dimensions while retaining as much information as possible in terms of variance.

One of the most important outputs of PCA is the explained variance ratio.

We first retrieve the PCA object from the pipeline.

    model_pca_extr = pipeline_pca.named_steps["pca"]
    variance_explained = model_pca_extr.explained_variance_ratio_

We can display the values as percentages:

    print(f"Variance Comp 1: {variance_explained[0]*100:.2f}%")
    print(f"ariance Comp 2: {variance_explained[1]*100:.2f}%")
    print(f"Total information covariance: {sum(variance_explained)*100:.2f}%\n")

this means that the two Principal Components retain approximately 98% of the total variance in the processed dataset.

# PCA Loadings

How do we understand what each Principal Component represents? To answer that we can examine the loadings.

The loadings indicate how strongly each processed feature contributes to each Principal Component.

First, I retrieve the names of the features after preprocessing.

    feature_names = (
        pipeline_pca
        .named_steps["preprocessor"]
        .get_feature_names_out()
    )
    
    feature_names

<img width="582" height="65" alt="image" src="https://github.com/user-attachments/assets/8256d974-bc53-4d5e-b075-2db4720c45bc" />

The names will include the transformations applied by the preprocessor.

We can now create a DataFrame containing the loadings.

    loadings = pd.DataFrame(
        model_pca_extr.components_.T,
        columns=["Comp 1", "Comp 2"],
        index=feature_names,
    )

We can sort the loadings according to their absolute contribution to Component 1:

    print(
        loadings.sort_values(
            by="Comp 1",
            key=abs,
            ascending=False
        )
    )

# How to Interpret Loadings

A loading tells me how strongly a processed feature contributes to a Principal Component.

For example:

num__Income : +0.69  num__Age : +0.69

This means that both Income and Age have relatively strong positive contributions to Component 1.

Therefore, Component 1 can be interpreted as being strongly related to the combination of:

Age + Income

Similarly, if Component 2 has:

City_Naples :+0.70 and City_Rome  : -0.70

then Component 2 is strongly associated with the distinction between these city categories.

The signs indicate the direction of the relationship with the component.

# Creating the PCA Chart

We can now visualise the two Principal Components.

    plt.figure(figsize=(8, 6))
    
    classes = [0, 1]
    
    colours = ["red", "green"]
    
    labels = [
        "Satisfied",
        "Not Satisfied"
    ]
    
    for cla, col, lab in zip(
        classes,
        colours,
        labels
    ):

    plt.scatter(
        X_pca[y == cla, 0],
        X_pca[y == cla, 1],
        color=col,
        label=lab,
        s=100,
        edgecolor="black",
    )

    plt.title(
        "PCA with Pipeline with mixed data type"
    )
    
    plt.xlabel("Comp 1")
    plt.ylabel("Comp 2")
    
    plt.legend()
    
    plt.grid(
        True,
        linestyle="--",
        alpha=0.7
    )
    
    plt.show()

# How to Interpret the PCA Chart

The position of each point is determined by the values of the processed features and their corresponding PCA loadings.

Therefore, a point is positioned according to the combined contribution of all the features to the Principal Components.

For example, if a customer has:

- relatively high Age;
- relatively high Income;

and both variables have positive loadings on Component 1, that customer will tend to have a higher Component 1 value.

# Key Takeaway

PCA is a dimensionality reduction technique that transforms the original features into a smaller number of Principal Components.

In this example, we start with mixed data containing:

Age
Income
City

The numerical variables are standardised and the categorical variable is converted using One-Hot Encoding.

The ColumnTransformer combines these preprocessing steps, and PCA then reduces the resulting feature space to two dimensions.

The explained variance ratio tells me how much of the variance is retained by each Principal Component, while the loadings help me understand which processed features contribute most strongly to each component.

The PCA plot provides a two-dimensional representation of the customers, which can then be used for visualisation or as input to further machine learning techniques.
