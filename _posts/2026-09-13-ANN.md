# ANN

An Artificial Neural Network (ANN) is a machine learning model made of interconnected artificial neurons. It is designed to learn relationships and patterns from data by adjusting numerical values called weights and biases.

An ANN is usually organised into three types of layers:

- Input layer – receives the input features.
- Hidden layers – transform the information and learn patterns from the data.
- Output layer – produces the final prediction.

# How does it work?

Each neuron receives one or more input values. 

Each input is multiplied by a weight, and a bias is added.

The basic calculation is:

$$
z = \sum_{i=1}^{n} w_i x_i + b
$$

where:

$x_i$ = input feature
$w_i$ = weight associated with the input
$b$ = bias
$z$ = weighted sum

The weighted sum is then passed through an activation function:

$$
a = f(z)
$$

The activation function determines the output of the neuron, and during training, the network changes the weights and biases so that its predictions become closer to the correct answers.

# Activation Functions

They allow neural networks to learn non-linear relationships.

# ReLU

ReLU (Rectified Linear Unit) is commonly used in hidden layers:

$$
f(x)=\max(0,x)
$$

is an activation function used in neural networks that turns all negative inputs into $0$ while leaving positive inputs unchanged.
It acts like an "ON/OFF" switch—deactivating neurons when the input is negative and passing the exact value through when it is positive.

# Sigmoid

Sigmoid converts a value into a number between 0 and 1:

$$
\sigma(x)=\frac{1}{1+e^{-x}}
$$

It is particularly useful for binary classification because the output can be interpreted as a probability.

# Softmax

Softmax is commonly used for multi-class classification.

Instead of producing one probability, it produces a probability for each class.

# Forward Propagation

Forward propagation is the process through which data moves from the input layer through the hidden layers to the output layer, and at the end of forward propagation, the network produces a prediction.
The prediction is not immediately considered simply correct or incorrect. The loss function first measures how far the predicted probability is from the actual value.

# Loss Function

The loss function measures how different the model's predictions are from the actual target values.

The network uses the loss to determine how its parameters should be changed.

For binary classification, a common choice is Binary Cross-Entropy:

$$
L = -[y\log(\hat{y})+(1-y)\log(1-\hat{y})]
$$

where:

$y$ = actual class
$\hat{y}$ = predicted probability

A prediction close to the correct value produces a smaller loss, while a confident incorrect prediction produces a larger loss.

# Backpropagation

Once the network has calculated a prediction and the loss, it needs to determine how the weights should change.

The process uses the chain rule of differentiation to calculate gradients.

Weights ← Gradients ← Loss

A gradient tells us how much the loss would change if a particular parameter changed.
For example:

Large gradient → parameter has a stronger effect on the loss
Small gradient → parameter has a smaller effect on the loss

Backpropagation works backwards through the network and calculates how much each weight contributed to the error.

The process uses the chain rule of differentiation to calculate gradients.

A gradient tells us how much the loss would change if a particular parameter changed.
Backpropagation itself calculates the gradients. An optimiser then uses those gradients to update the weights.

# Optimisation

An optimiser changes the weights and biases using the gradients calculated during backpropagation.

A simplified update can be represented as:

$$
w_{new}=w_{old}-\eta\frac{\partial L}{\partial w}
$$

where:

$w$ = weight
$L$ = loss
$\frac{\partial L}{\partial w}$ = gradient
$\eta$ = learning rate

The learning rate controls how large each update is.

Very small learning rate: learning can be slow

Very large learning rate: training can become unstable

Appropriate learning rate: gradual reduction of the loss

# Adam

Adam is a commonly used optimiser for neural networks.

It adapts the size of parameter updates using information from previous gradients. In many practical applications, it provides a useful starting point without requiring extensive manual optimisation.

# ANN Hyperparameters

Important ANN hyperparameters include:


Number of hidden layers:	Depth of the network

Number of neurons:	Capacity of each hidden layer

Activation function:	Type of transformation applied by neurons

Learning rate:	Size of weight updates

Optimiser:	Method used to update parameters

Batch size:	Number of observations processed before an update

Epochs:	Number of complete passes through the training data

Dropout:	Regularisation by randomly removing neurons during training

L2 regularisation:	Penalisation of large weights

Early stopping:	Stops training when validation performance stops improving
