# Convolutional Neural Network

A Convolutional Neural Network is a deep learning model designed specifically for processing grid-like data, such as images or videos.

While traditional neural networks treat images as flat lists of individual pixels, CNNs preserve the spatial structure, making them exceptionally effective at understanding patterns in visual data.

# Where are they used mainly

- Image Classification

- Object Detection & Localisation

- Medical Imaging

- Facial Recognition

# How CNN is made

A CNN is built by stacking 4 different layers in a pipeline 

Input -> Convolution Layer -> ReLU Activation -> Pooling Layer -> Fully Connected Layer -> Output Class

In particular:

*Convolutional Layer* uses small matrices called filters or kernels (e.g., $3 \times 3$ or $5 \times 5$ grids of numbers) that slide across the input image to detect features like edges, corners, and colour gradients.

*ReLU (Rectified Linear Unit) Activation Layer* introduces non-linearity into the network using a simple rule:

$$f(x) = \max(0, x)$$

It turns all negative pixel values to $0$ while keeping positive values unchanged, allowing the network to learn complex, real-world patterns rather than just simple linear mappings.

*Pooling Layer*  reduces the spatial dimensions (width and height) of the feature maps, which speeds up processing and reduces memory usage, by sliding a window across the image and keeping only the maximum value in each window.

*Fully Connected (FC) Layer* Located at the end of the CNN, this layer flattens the multidimensional feature maps into a 1D vector and connects every neuron to the output nodes to produce the final classification probabilities

# How Does it works

*1 Feature Extraction via Sliding Filters*

The filter slides across the input image pixel by pixel, and at each position, it performs element-wise multiplication with the image section beneath it and sums the result to create a single number in a new matrix known as a Feature Map.

*2 Non-Linear Activation*

The feature map passes through the ReLU function, and all negative numerical values are replaced with zero, highlighting only the activated positive features and removing unnecessary negative signals.

*3 Dimensionality Reduction*

The feature map is downsampled using Max Pooling, retaining only the strongest features from each local region, allowing detection of an object regardless of where it appears in the frame.

*4 Hierarchical Feature Learning*

Steps 1 to 3 are repeated across multiple deep layers.

*5 Final Classification*

The complex high-level features are flattened into a 1D vector and passed through a Fully Connected Layer. A Softmax activation function converts the raw output numbers into probability scores for each class category.
