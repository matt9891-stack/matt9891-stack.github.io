# K-means Implementation

How does this work: given a dataset containing numerical observations, the algorithm attempts to divide them into a predefined number of groups (K) by placing observations that are close to each other in the same cluster.

# Creating the Dataset
We create a small dataset containing two numerical variables, x and y.

# Choosing the Number of Clusters

One of the first decisions in K-Means is choosing the value of K.

K represents the number of clusters that the algorithm will create.

However, the dataset does not tell us directly which value of K should be used and for this reason, we can use the Elbow Method to investigate how the clustering solution changes for different values of K.

# Elbow method

The Elbow Method is based on the Within-Cluster Sum of Squares (WCSS) which measures how far the observations are from the centroid of the cluster to which they have been assigned.

The objective of K-Means is to minimise this value.

$$
WCSS = \sum_{k=1}^{K} \sum_{\mathbf{x}_i \in C_k}
\left|\mathbf{x}_i - \boldsymbol{\mu}_k\right|^2
$$

where:

- $K$ is the number of clusters;
- $C_k$ is cluster $k$;
- $\mathbf{x}_i$ is an observation belonging to cluster $k$;
- $\boldsymbol{\mu}_k$ is the centroid of cluster $k$;
- $|\mathbf{x}_i-\boldsymbol{\mu}_k|^2$ is the squared distance between the observation and its centroid.

A smaller WCSS means that the observations are, overall, closer to the centroids of their assigned clusters.

# Centroid

The centroid is the centre of a cluster and is calculated as the mean position of all observations belonging to that cluster.

$$
\mathbf{\mu}k =
\frac{1}{N_k}
\sum{\mathbf{x}_i \in C_k}
\mathbf{x}_i
$$

where:

- $\mathbf{\mu}_k$ is the centroid of cluster $k$;
- $N_k$ is the number of observations in cluster $k$;
- $\mathbf{x}_i$ is an observation belonging to cluster $k$;
- $C_k$ is cluster $k$.

# Elbow Method application

We calculate the WCSS for different values of K, from 1 to 10.

    wcss = []
    
    for k in range(1, 11):

    kmeans = KMeans(
        n_clusters=k,
        random_state=0
    )

    kmeans.fit(X)

    wcss.append(kmeans.inertia_)

The inertia_ attribute contains the WCSS calculated by K-Means for the fitted model.

We can then plot the results:

    plt.plot(
        range(1, 11),
        wcss,
        marker='o'
    )
    
    plt.title('Elbow Method')
    
    plt.xlabel('Number of clusters K')
    
    plt.ylabel('WCSS')
    
    plt.show()

The objective is not simply to select the value of K with the lowest WCSS, because increasing K will always tend to reduce WCSS, but to look for the point where the reduction in WCSS starts to become considerably smaller.

This point is known as the elbow.

# K-Means Model

    k = 3
    
    kmeans = KMeans(
        n_clusters=k,
        random_state=0
    )

At this stage, we have defined the number of clusters, but the observations have not yet been assigned to their final clusters.
